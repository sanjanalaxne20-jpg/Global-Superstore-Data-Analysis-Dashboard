# 📊 Global Superstore Data Analysis Dashboard

## 📌 Project Overview

This project presents an interactive **Global Superstore Data Analysis Dashboard** created using Power BI. The dashboard analyzes sales, profit, orders, customers, products and regional performance to identify important business trends and insights.

## 🎯 Objectives

- Analyze overall sales and profit performance
- Identify top-performing products and categories
- Compare regional and market performance
- Understand customer and order trends
- Track key business KPIs
- Support data-driven decision-making

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Microsoft Excel** – Source dataset
